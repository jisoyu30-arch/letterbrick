# 필사 문구 DB — 저작권 만료(퍼블릭 도메인) 100일치

작성일: 2026-07-30
파일: `pd-sentences-100.json` (100개, day 1-100)

## 저작권 안전 기준 (이 DB의 수록 원칙)

1. **한국 작가**: 사망일이 **1962-12-31 이전**인 작가만 수록.
   - 근거: 구 저작권법의 사후 50년 보호는 2012년까지 순차 만료되었고, 2013-07-01 시행된 사후 70년 연장은 **그 시점에 이미 만료된 저작물에 소급 적용되지 않는다.** 따라서 1962년 이전 사망 작가의 저작물은 만료 확정.
   - 1963년 이후 사망 작가(백석 1996, 서정주 2000, 로버트 프로스트 1963 등)는 **수록 금지**.
2. **외국 작가**: 같은 기준(사망 ≤1962)으로 원문은 만료. 단 **한국어 번역문은 번역가의 별도 저작권**이 있으므로:
   - 기존 출판 번역문을 절대 그대로 쓰지 않는다.
   - 이 DB의 한국어 문장은 전부 **자체 번역 초안**이며, `translationNote` 필드에 감수 필요 여부를 표시했다.
   - 원문이 확실한 경우 `textOriginal`에 원문을 수록했다 (영어·독일어·프랑스어·한문·일본어).
3. **표기 현대화**: 한국 근대 작품은 현대 맞춤법으로 표기했다. 원문 표기(옛 맞춤법)와의 대조는 `verifyAt` 링크에서 가능.
4. **짧은 명언류 주의**: 인터넷에 떠도는 "명언"은 오귀속(misattribution)이 많아, 출전이 실제 작품으로 특정되는 문장만 수록했다.

## 필드 설명

| 필드 | 의미 |
|---|---|
| `day` | 1-100 배포 순서 제안 |
| `edition` | growth(구조 훈련용 짧은 문장) / healing(음미용 긴 문단) |
| `text` | 필사 문구 (한국어) — 외국 작품은 자체 번역 초안 |
| `textOriginal` | 원문 (한국 작품은 null) |
| `authorDied` | 사망 연도 — 저작권 만료 판단 근거 |
| `pdBasis` | 만료 근거 요약 |
| `translationNote` | null(한국 원문) / "draft"(자체 번역 초안, 감수 필요) / "convergent"(짧은 문장이라 어떤 번역도 비슷해짐 — 기존 역서와 우연히 겹쳐도 문제 소지 낮음, 그래도 감수) |
| `confidence` | high(정확한 자구 확신) / medium(자구 재확인 필요) |
| `verifyAt` | 원문 대조 진입점 (위키문헌·구텐베르크 등) |
| `approvalStatus` | 전부 "pending" — 아래 검수 절차 통과 후 "approved"로 변경 |

## 출시 전 검수 절차 (앱 노출 전 필수)

1. `confidence: "medium"` 항목부터 `verifyAt` 링크에서 **자구 대조** → 수정 후 high로 승격
2. `translationNote: "draft"` 항목은 작가님이 번역문 감수 (하담 문체 기준)
3. 검수 통과 항목만 `approvalStatus: "approved"` 로 변경
4. 앱 데이터(index.html의 SENTENCES / quotes-growth.js)로 옮길 때 approved만 이관
