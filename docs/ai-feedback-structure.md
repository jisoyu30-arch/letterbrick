# 레터브릭 AI 평가 피드백 구조 정리

> GPT·Gemini·Claude 의견 종합 후 최종 정리 버전

---

## 1. 피드백 체계 개요

레터브릭의 AI 피드백은 **두 축**으로 운영된다.

| 축 | 이름 | 목적 | 평가 방식 |
|---|---|---|---|
| A | **구조 연습 채점** (STRUCT) | 원문 구조를 얼마나 잘 변형했는가 | ★ 별점 (1~5) + 코멘트 |
| B | **AI 코치 평가** (CREATIVE) | 자기 목소리로 글을 썼는가 | ★ 별점 (1~5) + 감상문 |

두 축 모두 **최대 2~3회 재시도**를 허용하며, 시도마다 피드백 톤과 깊이가 달라진다.

## 2. 구조 연습 피드백 (STRUCT_FB)

### 2-1. 1차 시도 (score: 74/100)

| 섹션 | 라벨 | 핵심 내용 |
|---|---|---|
| ① | **기법 인식** | 원문의 핵심 구조(대조, 역설 등)를 감지했는지 확인. 두 절의 대비 긴장감 평가 |
| ② | **구체성 점검** | 추상적 감정 vs 구체적 사물/행위. "독자가 장면을 볼 수 있는가" 기준 |
| ③ | **다음 시도를 위한 조언** | 핵심 명사 1개를 구체적 사물로 교체하라는 실행 가능한 지시 |
| 💡 | **Tip** | "원문의 핵심 동사를 다른 동사로 바꿔 다시 써보세요" |

### 2-2. 2차 시도 (score: 83/100)

| 섹션 | 라벨 | 핵심 내용 |
|---|---|---|
| ① | **발전 포인트** | 1차 대비 구체성 향상 인정. 모방→적용 전환 확인 |
| ② | **남은 과제** | 두 절의 길이 균형, 밀도 보완 포인트 |
| ③ | **이 문장의 강점** | "자신의 소재로 소화하려는 시도 자체가 핵심" — 격려 |
| 💡 | **Tip** | "소리 내어 읽어보세요. 어색한 부분이 수정 지점" |

## 3. 창의적 글쓰기 피드백 (CREATIVE_FB)

### 3-1. 1차 시도 (score: 78/100)

| 섹션 | 라벨 | 핵심 내용 |
|---|---|---|
| ① | **감정·이미지 선명도** | 직접 서술 vs 구체적 장면. "빈 컵을 바라보는" 예시로 보여주기 |
| ② | **오늘 배운 기법 연결** | 대비·열거·역설 등 당일 기법의 활용도 체크 |
| ③ | **발전 가능성** | "한 문장을 깊이 파는 것 > 열 문장을 넓게 쓰는 것" |
| 💡 | **Tip** | "가장 마음에 드는 문장 하나만 골라, 그걸로 다시 시작" |

### 3-2. 2차 시도 (score: 87/100)

| 섹션 | 라벨 | 핵심 내용 |
|---|---|---|
| ① | **이전 대비 발전** | 추상→구체 전환 시도 인정. 기법의 자연스러운 체화 확인 |
| ② | **이 글의 강점** | 자기 경험/기억의 소재화 → "필사 훈련의 목표" 연결 |
| ③ | **앞으로의 방향** | 인상적인 한 문장을 씨앗으로 다음 글에 연결 |
| 💡 | **Tip** | "가장 좋은 문장을 따로 기록해두세요" |

## 4. 실시간 분석 엔진 (analyzeStructure / analyzeCreative)

정적 피드백 외에, 사용자 입력을 실시간 분석하는 로컬 엔진이 작동한다.

### 4-1. 구조 연습 분석 (`analyzeStructure`)

**평가 항목 (가중치 합산 → ★1~5)**

| 항목 | 조건 | 점수 |
|---|---|---|
| 유사도 차단 | similarity > 0.85 또는 overlap > 0.8 → 즉시 ★1 | — |
| 시작 변화 | 첫 단어가 원문과 다름 | +1.0 |
| 문장 유형 변화 | 평서↔의문↔명령 등 전환 | +1.0 |
| 어휘 변화 | overlap < 0.4 (과감) / < 0.6 (적당) | +1.5 / +1.0 |
| 길이 적절성 | 원문 대비 60~150% | +0.5 |
| 전체 변형도 | similarity < 0.5 & 20자 이상 | +1.0 |

**피드백 구성**
- `AI 코치의 구조 분석`: 항목별 감상형 코멘트 (랜덤 풀에서 선택)
- `기법 연결`: 당일 기법명 추출 후 적용 여부 판정
- `표기 다듬기`: 맞춤법·띄어쓰기 advisory 오류 표시
- `Tip`: 6종 랜덤 풀

### 4-2. 창의적 글쓰기 분석 (`analyzeCreative`)

**평가 항목 (가중치 합산 → ★1~5)**

| 항목 | 조건 | 점수 |
|---|---|---|
| 유사도 차단 | similarity > 0.8 → 즉시 ★1 | — |
| 글 길이 | 15단어 이상 / 8단어 이상 | +1.0 / +0.5 |
| 원문 연결 + 독자성 | overlap 0.1~0.5 | +1.0 |
| 문장 완성도 | 종결부호로 끝남 | +0.5 |
| 구체적 이미지 | 감각어 패턴 매칭 (소리, 빛, 냄새, 바람...) | +1.0 |
| 독창성 | similarity < 0.3 & 10단어 이상 | +1.0 |

**피드백 구성**
- `감정·이미지 분석`: 항목별 디테일 합산
- `기법 활용`: 당일 기법 적용 여부 판정
- `표기 검수`: advisory 오류 표시
- `Tip`: 3종 랜덤 풀

## 5. 힐링 에디션 분석 (analyzeCreative 오버라이드)

힐링 에디션에서는 `analyzeCreative`가 **긍정 소감 톤**으로 오버라이드된다.

### 추가된 기법별 탐지 패턴

| 기법 키워드 | 탐지 패턴 | 예시 |
|---|---|---|
| 역설 / 역접 / 양보 | 만·지는·그러나·하지만 | 대비/역접 구조 |
| 반복 / 병치 | 동일 단어 2회 이상 출현 | 리듬 반복 |
| 비유 | 처럼·같은·닮아 | 은유/직유 |
| 부정 / 확장 | 아니라·않는·없는 | 부정을 통한 의미 확장 |
| 공백 / 명명 | 못 할·이름 모를·무엇 | 이름 붙이지 않기 |
| 주어 이동 | 스스로·저절로·그것이 | 주어 전환 |
| 명령 / 권유 | 하라·세요·십시오 | 명령형 종결 |
| 현재진행 | 하고 있·되고 있·살아 있 | 현재진행형 |

### 피드백 톤 분기 (★ 기준)

| 별점 | 톤 | 시작 문장 |
|---|---|---|
| ★4~5 | 감탄 | "이 글을 읽으면서 잠시 멈추게 됐어요." |
| ★3 | 격려 | "글에서 쓰고 싶은 마음이 느껴져요." |
| ★1~2 | 응원 | "글을 쓰기로 한 것 자체가 용기예요." |

## 6. 공통 검증 레이어

모든 분석 함수 진입 전 `detectErrors()`가 실행된다.

| 유형 | 처리 |
|---|---|
| **blocking** | 평가 중단, 오류 메시지 반환 (빈 입력, 특수문자 등) |
| **advisory** | 평가는 진행, 마지막에 "표기 다듬기/검수" 섹션으로 표시 |

추가 검증:
- 공백 문제 감지 → confirm 팝업으로 사용자 선택
- OCR 입력 지원 (손글씨 사진 → 텍스트 변환)
- 중복 제출 감지

---

## 7. 피드백 데이터 흐름

```
사용자 입력
  ↓
detectErrors() → blocking이면 중단
  ↓
analyzeStructure() / analyzeCreative()
  ↓
{ stars, sections[], errors[], tip }
  ↓
UI 렌더링 (air-card)  +  pastRecords 저장
  ↓
localStorage 동기화  →  Google Sheets 백업
```

## 8. 설계 원칙 (AI 3종 의견 종합)

| 원칙 | 설명 |
|---|---|
| **비교하지 않는다** | 다른 사용자와 비교 없음. 자기 이전 시도와만 비교 |
| **구체적으로 짚는다** | "잘했어요" 대신 사용자 문장의 특정 단어를 인용해서 피드백 |
| **실행 가능한 조언** | "더 잘 쓰세요" 대신 "핵심 명사 1개를 바꿔보세요" |
| **감상문 톤** | 채점표가 아니라 독자로서의 감상. 특히 힐링 에디션 |
| **재시도 유도** | 1차 피드백은 과제를 남기고, 2차에서 발전을 인정 |
| **기법 연결 필수** | 모든 피드백에 당일 배운 기법과의 연결고리 포함 |
