# 예비 문장 파일

한국:외국 비율 조정 과정에서 배치되지 않은 문장·문단입니다. 전부 진위 검증을 통과한 것이라 언제든 투입할 수 있습니다.

## 파일
- `reserve-growth.json` — 성장편 미배치 문장
- `reserve-healing.json` — 힐링편 미배치 문단

## 왜 남았나
성장편은 하루 A/B 두 문장이 필요해 365일이면 730문장을 씁니다. 검증 통과 풀이 그보다 많으면 잉여가 생깁니다. 힐링편도 같습니다.

비율 조정 방침상 **외국 문장을 먼저 소진**하므로, 남는 것은 대부분 한국 작가입니다.

## 쓰임새
- 배치된 문장에 문제가 발견됐을 때 교체용
- 특정 작가 편중을 줄일 때 대체용
- 2년차 커리큘럼 시드

## 주의
`pool-growth-final.json` / `pool-healing-final.json` 이 전체 풀이고, 예비 파일은 그중 미배치분만 추린 것입니다. 재배치를 다시 돌리면 예비 파일도 새로 생성됩니다.
