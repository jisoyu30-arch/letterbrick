# 레터브릭 1년치 커리큘럼 — 작업 산출물

## 파일
- `curriculum.json` — 최종 채택된 52주 커리큘럼 (3개 독립 설계를 종합)
- `curriculum-alternatives.json` — 탈락한 설계 3건 (탈락 근거 비교용)
- `pool-verified.json` — 진위 검증을 통과한 문장 840개
- `pool-rejected.json` — 탈락 문장 (원문에서 확인 실패)

## 검증 방법 (에이전트가 아니라 코드로 수행)
각 문장의 `sourceUrl`을 실제로 받아와 인용문이 그 안에 있는지 **글자 단위로 대조**했다.
- `exact` 665건 — 공백·문장부호를 무시한 정규화 후 완전 일치
- `partial` 2건 — 12자 창 슬라이딩 일치율 70% 이상 (표기 차이)
- `translation-url-ok` 173건 — 외국 작가. 한국어는 자체 번역이므로 원문 대조 불가, URL 접근성만 확인
- 탈락 4건 — 위키문헌에 전사되지 않은 윤동주 1955년 증보판 수록작

검증 중 발견해 수정한 것:
- 윤동주 25건이 처음 NOT-FOUND로 나왔으나, 해당 문서가 스캔본 PDF를 transclusion 하는 구조라 raw 위키텍스트에 본문이 없었던 것. 렌더링 API로 재대조해 21건 복구.
- 나도향 6건의 URL이 오타(`그믘달`)로 404. 검색 API로 올바른 문서를 찾아 복구.

## 규칙 준수 (코드 스캔, 위반 0건)
- 1962년 12월 31일 이전 사망 저작자만 사용
- 친일 명단(친일인명사전·705인·문학인 42인) 등재자 전원 배제
- 외국 작가는 자체 번역, 남의 번역본 미사용
