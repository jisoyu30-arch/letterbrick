조사일: 2026-09-11
조사 방법: 구글플레이 공개 페이지 및 리뷰 API 직접 수집, 애플 App Store iTunes API 및 리뷰 RSS 직접 수집, 교보문고·예스24 검색 페이지 직접 조회, 웹 검색

## 이 조사에서 확인한 것 / 확인하지 못한 것

1. **확인함** — 한국 "필사 전용 앱" 시장은 존재하지만 규모가 극단적으로 작다. 필사 전용 앱 중 안드로이드 다운로드 1만 이상은 2개뿐이고(모두의필사 1만+, 민음사 세계문학 일력 1만+), 나머지는 대부분 50-1,000 다운로드 수준이다. 반면 인접 시장(독서기록 북모리 100만+, 글쓰기 씀 50만+)은 훨씬 크다.
2. **확인함** — 레터브릭의 핵심 차별점으로 가정했던 "AI 문장 첨삭"은 이미 경쟁자 2곳이 탑재해 판매 중이다. 씀(50만+ 다운로드)은 "AI 문장 교정", 타이피는 "인공지능 언어 모델이 첫 독자이자 편집자가 되어 글을 피드백"을 유료 기능으로 팔고 있다.
3. **확인함** — 필사책 출판 시장은 살아 있다. 예스24 "필사" 검색 결과 5,763건, 교보문고 3,765건이며 2026년 신간이 계속 나오고 있다. 대표 히트작의 예스24 판매지수는 236,496이다.
4. **확인하지 못함** — 네이버 데이터랩·구글 트렌드의 "필사" 검색량 추이 원본 데이터, 인스타그램 해시태그별 정확한 게시물 수, 밀리의서재를 제외한 대부분 서비스의 정확한 유료 구독자 수. 이 항목들은 아래 본문에서 개별적으로 "확인 못 함"으로 표시했다.
5. **확인하지 못함** — 씀·민음사 일력 등의 정확한 구독가는 구글플레이가 인앱 상품 가격을 지연 로딩해 페이지 소스에서 직접 확정하지 못한 건이 있다. 확정한 것과 추정한 것을 본문에서 구분했다.

## A. 직접 경쟁 — 한국 필사·글쓰기 앱

### A-0. 먼저, 시장 규모의 실체

구글플레이에서 "필사"로 검색해 나온 앱들의 **실제 다운로드 수**를 하나씩 확인한 결과다. (각 앱 구글플레이 페이지에서 직접 수집, 2026-09-11 기준)

- 밀리의 서재 — 500만+ (https://play.google.com/store/apps/details?id=kr.co.millie.millieshelf)
- 북모리(독서기록) — 100만+ (https://play.google.com/store/apps/details?id=net.tonysoft.bookmory)
- 씀 : 일상적 글쓰기 — 50만+ (https://play.google.com/store/apps/details?id=com.projectm.ezbrother.ssm)
- 하루북(책만들기) — 10만+ (https://play.google.com/store/apps/details?id=com.espressobook.doy)
- 모두의필사 / 어쨌든, 필사 — 1만+ (https://play.google.com/store/apps/details?id=com.thehama.wisesaying)
- 세계문학 일력(민음사) — 1만+ (https://play.google.com/store/apps/details?id=com.minumsa.wl.dailycalendar)
- 타이피 — 1만+ (https://play.google.com/store/apps/details?id=co.typie)
- 필사포엠 — 1천+ / Quotely — 1천+ / 퀄렉트 — 1천+
- 필사(Fillsa) — 500+ / 오늘의 필사 — 500+ / 북담 — 500+ / 필사노트 — 500+
- 박한평 문장집 — 100+ / 북클립 — 100+ / 손끝 필사 — 50+ / 여운 — 50+

읽는 법: **"필사"를 정면으로 내건 앱 중 다운로드 1만을 넘긴 것은 2개뿐이다.** 그 2개 중 하나(민음사)는 출판사 브랜드로 밀어붙인 것이고, 다른 하나(모두의필사)는 개인 개발자 수준의 무료 앱이다. 나머지 필사 앱은 사실상 아무도 쓰지 않는다.

동시에 애플 App Store에서 "필사", "문장수집"으로 검색하면 2025-2026년에 출시된 개인 개발자 앱이 수십 개 쏟아진다(iTunes Search API 직접 조회). 평점 수가 0-40개인 앱이 대다수다. **진입장벽이 거의 없고, 승자도 없는 상태다.**

### A-1. 씀 (ssm) — 가장 위협적인 직접 경쟁자

- 형태: 안드로이드·iOS 앱 (PC 버전 없음, 개발 검토 중이라고 개발사가 리뷰 답글에서 밝힘)
- 개발사: (주)텐비 / 10B Inc.
- 규모: 안드로이드 50만+ 다운로드, 리뷰 1.02만개, 평점 4.8 / iOS 평점 4.81, 평가 1,107개
- 출시 2016-07-12, 최종 업데이트 2026-09-03 — **10년째 살아 있고 지금도 활발히 개발 중**
- 가격: 구글플레이 인앱 상품 범위 ₩3,900 - ₩29,000 (월간·연간 멤버십 구조. 월 3,900원 / 연 29,000원으로 보이나 상품별 정가는 확정하지 못함)
- 출처: https://play.google.com/store/apps/details?id=com.projectm.ezbrother.ssm , https://apps.apple.com/kr/app/id1118780107

핵심 기능 (앱 설명 원문 기준):
- 매일 오전·오후 7시 **글감 제공** — 레터브릭의 "매일 한 문장"과 같은 자리를 차지하는 후크
- **"AI 문장 교정과 맞춤법 검사 기능으로 더 정확하고 매끄럽게 다듬어진 글을 완성"** — 유료 기능
- 다른 사람 글 읽기·구독·담아가기 (커뮤니티)
- 쓴 글을 모아 종이책 제작·판매

레터브릭과 겹치는 지점: 매일 글감 → 창작 → AI 교정이라는 흐름 전체가 겹친다. 레터브릭의 3-4단계(변형 연습, 자기 문장 창작 + AI 채점)와 기능적으로 같은 자리다.

레터브릭과 다른 지점: 씀은 **고전 문장을 주지 않는다.** "말투", "여름", "그리움" 같은 단어 글감만 준다. 구조 분석·변형 연습 같은 훈련 단계가 없고, AI는 "교정"(맞춤법·문장 다듬기)이지 "루브릭 채점"이 아니다. 그리고 씀의 실사용자는 리뷰 원문상 **학생 비중이 매우 높다.**

리뷰에서 반복되는 불만 (직접 수집한 원문):
- 유료화 반발이 가장 크다. 2024년 11월 대규모 업데이트에서 맞춤법 검사와 글 작성 일부를 유료로 돌리며 폭발했다. "2016년도부터 사용한 유저입니다. 무료로 제공하던 기능을 유료로 돌리다뇨; 일회성 결제도 아니고 구독 시스템으로 돌려서 더 황당하네요."(닉네임뭐함, 3점) / "돈 주고 글을 써야하는 글쓰기 어플 — 가치가 없음"(우웩똥겜, 1점) / "글을 쓴 후에 저장하려면 광고를 봐야 저장이 되게끔 한 부분은 기분이 상하네요. 본인의 글이 인질로 잡힌 느낌"(많이 아쉬움, 1점)
- 데이터 소실. "5년전부터 사용하면서 수십개의 글들을 적어뒀었는데 하루아침에 사라져 버리니"(김가락., 1점) / "족히 4-5년은 써 온 제 수백 개의 글들이 모두 제 손에서 사라졌습니다"(Cloud_moon917, 3점)
- 렉·저장 실패. "잔뜩 쓴 글을 저장할 때, 맞춤법 검사 오류가 떠서 누르면 오류 화면이 나타나고 그동안 쓴 글이 모두 날아간다."(Whizz Xanadu, 1점)
- 커뮤니티 품질 저하. "잼민이들 카르텔로 일기쳐쓰면서 제대로된 문학이 묻히는것좀 어떻게해봐요"(레크Rek, 1점)
- 맞춤법 검사 유료화에 대한 반복 요구. "최소한 맞춤법 검사는 다른 광고를 늘리더라도 무료로 해야하는게 맞다고 봄"(폭렬불패, 3점)

**레터브릭에 주는 시사점**: 씀의 커뮤니티 품질 불만과 학생 편중은 성인 대상 진지한 훈련 서비스가 비집고 들어갈 틈이다. 반대로, 씀이 이미 50만 다운로드와 10년의 축적을 가지고 같은 흐름을 팔고 있다는 사실은 레터브릭이 "새로운 카테고리"가 아니라는 뜻이다.

### A-2. 타이피 (Typie) — AI 첨삭을 이미 파는 유료 글쓰기 앱

- 형태: 앱 + PC 웹 (https://typie.co), 개발사 PENXLE COMPANY
- 규모: 안드로이드 1만+ 다운로드, 리뷰 142개, 평점 3.2 / iOS 평점 3.85, 평가 105개
- 가격: 인앱 상품 ₩2,900 - ₩29,000. **월 2,900원**은 사용자 리뷰에서 교차 확인됨("달 2900원이 아깝냐 싶을 수도 있는데")
- 출처: https://play.google.com/store/apps/details?id=co.typie , https://apps.apple.com/kr/app/id6745595771

핵심 기능 중 레터브릭과 직접 겹치는 것 (앱 설명 원문):
- **"인공지능 언어 모델이 첫 독자이자 편집자가 되어 글을 꼼꼼하게 피드백해요"**
- "맞춤법 검사기가 탑재되어 간편하게 글을 교정할 수 있어요"
- 매일 쓴 글자 수 추적, 습관 통계

**타이피 사례는 레터브릭에 가장 중요한 경고다.** 타이피는 2026년 중 무료 플랜을 없애고 전면 유료로 전환했고, 그 결과 평점이 3.2까지 떨어졌다. 리뷰 105건 중 28건이 1-3점이며 대부분 유료화 반발이다.

- "이제 결제를 하지 않으면 사실상 앱 사용 자체가 불가하게 변경되었네요 (…) 그 돈내고 불쾌하게 앞선 글들 수정 할 바에는 타사 앱 '씀'을 쓸 것 같고"(아퍼라아야, 1점, 추천 10)
- "무료일땐 그냥 썼는데 유료로 바꾸니까 굳이..? 돈 내면서 쓰기는 애매한 앱.. 솔직히 폰트 바꿀수 있는것 빼고는 그냥 노트 기본 앱이랑 다른 점을 모르겠음"(옹심, 3점)
- "구독을 안 하면 글을 못 쓰게 하는 건 좀 아니라고 봅니다. 다른 앱 써야겠네요."(윤지아, 1점)
- 개발사 답글도 강경했다. "타이피는 유료 앱으로, 결제하지 않으시면 앱 사용이 불가능합니다. 다른 앱 사용 부탁드립니다." — 이 응대 자체가 추가 반발을 불렀다.

한편 AI 기능 자체에 대한 평가는 나쁘지 않다. "ai 피드백이 매우 유용하고 시스템도 직관적이고 편하긴 한데"(boxwood mr., 2점 — 별점은 무선 키보드 버그 때문) / "자동 저장 기능 AI기능이 생각보다 너무 유용해서 계속 쓸 생각 있어요"(5점).

**시사점**: AI 첨삭은 유용하다고 평가받지만, 그것만으로 유료 전환을 정당화하지 못했다. 사용자는 "AI 피드백이 있으니 돈을 낸다"가 아니라 "기본 기능까지 막으니 화가 난다"로 반응했다.

### A-3. 민음사 세계문학 일력 — 포지셔닝이 가장 가까운 경쟁자

- 형태: 앱 (안드로이드·iOS), (주)민음사. "민음사와 타이핑웍스가 함께합니다"
- 규모: 안드로이드 1만+ 다운로드, 리뷰 169개, 평점 3.3 / iOS 평점 4.14, 평가 73개
- 가격 모델: **연 단위 유료 앱**. 2025년판과 2026년판이 별도 유료 앱으로 판매됨. 정확한 가격은 확인하지 못했으나, 사용자 리뷰에 "얼마 안 하긴 하지만"이라는 표현이 있어 저가로 추정
- 출처: https://play.google.com/store/apps/details?id=com.minumsa.wl.dailycalendar , https://apps.apple.com/kr/app/id6752370745

앱 설명 원문: "하루하루, 세계문학 전집 중 추천된 글을 **필사**하며 하루를 시작할 수 있어요. 필사를 하며 떠오른 감상을 **메모**로 남기고, 그날의 감정을 되돌아보세요."

**이것은 레터브릭 힐링편과 거의 같은 제품이다.** 매일 고전 문장 하나 → 필사 → 그에 대한 감상 기록. 차이는 민음사가 세계문학전집이라는 라이선스 번역 자산과 출판사 브랜드를 갖고 있다는 점, 레터브릭이 문단별 고유 질문과 4단계 훈련 구조를 갖고 있다는 점이다.

리뷰에서 반복되는 불만:
- 결제·구매복원 오류가 압도적이다. 최근 리뷰 120건 중 70건이 1-3점이며 상당수가 이 문제다. "25년 12월에 2026년 세계문학일력을 구매했습니다만, 2월 중 결제가 취소되었다고 나오더니, 이후 구매 복원을 눌러도 아무것도 진행되지 않습니다"(양은진, 1점)
- 매년 재구매 구조에 대한 불만. "2025년도에 사면 또 구매해야하나요?"(행복햅, 1점) / "이거 유료구매하면 호구 아니면 허세. 공짜로 줘도 쓸까말까인데 무슨생각으로 유료앱인지?? 애초에 책 팔아먹으려고 만든앱인걸"(그롬, 1점)
- 필사 UX 결함. "필사하고 저장이 안돼요ㅠㅠ 필사 후에 그냥 나가기 버튼만 있어서 적어놓은 게 다 지워지는 일이 반복"(캐란의 정찰병, 4점) / "필사할 때 글자를 잘못입력했을 때 지워지지않고 먹통이 됩니다 빨리 고쳐졌음 좋겠어요 필사할 때마다 스트레스받아요"(몽글, 3점) / "중간에 잘못쓰면 그 부분만 수정할 수 있으면 좋겠어요"(buri_i_i, 2점)

- 씀: 맞춤법 검사·저장 기능 유료화 → 10년 사용자 이탈, "글이 인질로 잡힌 느낌"

공통 구조: **사용자가 이미 만든 자기 창작물에 대한 접근을 과금 조건으로 걸면 반드시 폭발한다.** 레터브릭은 유료 베타 설계 시 이 선을 넘지 않아야 한다. 현재 계획(무료는 로컬 코치 분석, 유료는 라이브 AI 쿼터 6회)은 이 함정을 피하는 구조로 보인다. 사용자가 이미 쓴 필사 기록과 창작물의 열람·수정은 어떤 경우에도 무료로 열어두는 것이 안전하다.
