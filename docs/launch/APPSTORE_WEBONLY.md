# 앱스토어 수수료와 웹 온리 전략

조사일 2026년 9월 11일 · 애플·구글 공식 문서 직접 확인

## 결론

**웹 온리로 시작하는 것이 현재 규제 환경에서 압도적으로 유리하다.** 근거 셋.

1. 한국 앱스토어에서 애플 제3자결제는 **26% 정액**이고 소규모 비즈니스 프로그램(15%) 할인이 적용되지 않는다. 소규모 개발자에게는 IAP보다 11%p 더 비싸다.
2. 애플은 미국 스토어프론트에서만 아웃링크를 허용한다. **한국은 외부 웹 결제 링크가 금지**다.
3. 앱 없이 유료 구독을 성공시킨 한국 사례가 문서로 확인된다.

## 결정적 사례 — 롱블랙

레터브릭이 참고할 가장 정확한 선례다.

- 2021년 9월 창간, iOS 앱 최초 출시 2023년 10월 22일 → **약 2년 1개월간 앱 없이 운영**
- 월 4,900원 구독, **2023년 상반기 월 구독 갱신율 87%**
- 회원 평균 월 16회 방문, 3분의 1은 주 1회 이상
- 2023년 9월 기준 누적 조회 2,507만 건, 콘텐츠 642개 약 582만 자
- 창간 2개월 만에 시드 11억원 유치
- 출처 http://www.journalist.or.kr/news/article.html?no=54421, https://apps.apple.com/kr/app/id6450910866

**앱 푸시 없이 갱신율 87%를 만든 장치 세 가지** — 필사 서비스에 그대로 이식 가능하다.
- **24시간 안에만 읽을 수 있다는 제약**
- **출석 스탬프** (2022년 2월 도입, 19개월간 256만 개)
- **문장 스크랩** (2023년 4월 도입, 5개월간 64만 장)

세 번째는 레터브릭이 이미 하고 있는 일이다.

## 스티비 — 앱 없이 정기결제를 위탁하는 경로

- iOS 앱이 **지금도 없다** (Apple 검색 API 조회 0건)
- 월 1회 이상 발송 사용자 5,700명, 월 발송량 2억 9,000만 통, 법인 설립 이후 7년 연속 흑자

- 월간(매월 같은 날 자동결제)·연간·1회 구독 지원, 매월 15일 정산서·25일 지급

**PG 자체 계약이 부담이면 스티비로 과금 의사를 먼저 검증한 뒤 자체 PG로 옮기는 2단계가 현실적이다.**

## 애플 수수료 (2026년)

**소규모 비즈니스 프로그램(SBP)** — https://developer.apple.com/kr/app-store/small-business-program/
- 표준 30%, SBP 15%. 직전 연도 순수익 100만 달러 이하면 자격, **신규 개발자는 자동 자격**
- 적용 시점: 승인된 회계월 종료 후 15일
- SBP 가입자는 구독도 1년차부터 15% (2년차 대기 불필요)
- **부가 혜택: 최초 다운로드 200만 회 미만이면 Apple Foundation Models를 클라우드 API 비용 없이 사용 가능.** 레터브릭 AI 채점 비용과 직접 관련된다

**구독 2년차 규칙** — 1년차 70%, 유료 서비스 1년 누적 후 85%. 무료 체험과 갱신 연장은 일수에서 제외. 해지 후 60일 이내 갱신하면 일수가 이어지고 60일 초과 시 0으로 초기화

**한국에서 외부 결제 링크는 불가** — 심사 지침 3.1.1(a) 원문: "In all other storefronts, except for the United States storefront... apps and their metadata may not include buttons, external links, or other calls to action that direct customers to purchasing mechanisms other than in-app purchase."
단 3.1.3에 따라 **앱 밖 커뮤니케이션(이메일 등)으로 웹 구독을 안내하는 것은 허용**된다.

**한국 제3자결제(StoreKit External Purchase Entitlement)** — https://developer.apple.com/support/storekit-external-entitlement-kr
수수료 26%, **SBP 요율 적용 안 됨**, 웹뷰 결제 금지, IAP와 병행 불가, 한국 전용 별도 바이너리, 사전 승인 PSP는 KCP·이니시스·토스·NICE, 환불·고객지원은 전적으로 개발사 책임

**3.1.3(f)** — "Free apps acting as a stand-alone companion to a paid web based tool... do not need to use in-app purchase, provided there is no purchasing inside the app, or calls to action for purchase outside of the app." 웹에서만 결제받고 앱은 로그인 전용으로 두는 경로의 근거 조항이다.

## 구글 플레이 수수료

**현재 한국 (2026년 12월 31일 이전)** — 첫 100만 달러 15%, 초과 30%, **자동갱신 구독은 규모 무관 15%**

**2026년 개편** — 미국·영국·EEA 2026년 6월 30일 시행, 호주·일본 9월 30일, **한국 2026년 12월 31일**, 나머지 2027년 9월 30일.
서비스 수수료와 결제 수수료 분리. 자동갱신 구독은 서비스 10% + Play 결제 5% = 실효 15%로 사실상 동일.

**한국은 아웃링크 허용** — 임베디드 웹뷰로 앱 내 표시, 서비스 수수료 4%p 인하. 15% 구간이면 **11%**. 애플과의 결정적 차이다.

**Play 결제 예외** — "앱 내에서 구매할 수 없고 다른 곳에서 구매한 콘텐츠에 로그인해 접근만 하는 앱"은 Play 결제 의무가 없다. 웹 온리 판매 + 앱은 열람 전용 전략의 근거.

## PWA를 스토어에 올릴 수 있는가

**애플 4.2** — "Your app should include features, content, and UI that elevate it beyond a repackaged website."
2025년 말-2026년 4월 반복 관측된 거절 문장: "your app provides a limited user experience as it is not sufficiently different from a mobile browsing experience." 프레임워크와 무관하게 나타난다.

통과 조건: 네트워크 없이도 콘텐츠 표시, 브라우저가 못 하는 기기 기능(알림·카메라·파일 저장·생체인증·위젯), 콜드 런치에서 핵심 기능 도달 가능한 데모 경로. **웹 표준 기능(WebSpeech API 등)은 네이티브 기능으로 인정되지 않는다.**

**구글 TWA** — 웹뷰 스팸 정책은 "사이트 소유자의 허가 없이"가 핵심이므로 자기 사이트를 감싸는 것은 위반이 아니다. 단 디지털 재화 판매 시 Play 결제 필수. 2026년 실무 이슈로 TWA 빌드가 "테스터가 참여하지 않았다" 거절을 자주 받는다는 보고가 있어 네이티브 WebView·Capacitor 재구축이 권장된다.

**웹 온리라도 iOS 16.4+ 홈 화면 추가 시 Web Push와 배지가 된다.** 매니페스트 display가 standalone/fullscreen이어야 하고 알림 권한 요청은 사용자 직접 상호작용에 대한 응답이어야 한다.

## 한국 인앱결제 강제금지법 — 아직 미확정

2023년 10월 6일 방통위가 시정조치안 통보(구글 475억, 애플 205억). **2026년 9월 11일 현재까지 과징금은 확정되지 않았다.** 2026년 8월 12일 제27차 전체회의에서 심의 재개했으나 "추후 의결"로 정리.

**아웃링크를 신뢰하고 설계하면 안 된다.**

## 레터브릭 실무 결론

**A.** 웹 온리로 시작한다. PG 수수료 3% 안팎 vs 앱스토어 15-26%.

**B.** 나중에 앱을 낸다면 **구글 플레이가 먼저**다. 한국에서 아웃링크 허용(4% 인하), TWA가 정책 위반이 아니다.

**C.** 애플은 두 갈래. IAP + SBP 15%(신규 자동 자격, Apple Foundation Models 무료 덤) 또는 3.1.3(f) 로그인 전용 앱. 후자도 4.2 심사는 별도로 통과해야 한다.

**D.** 롱블랙의 리텐션 장치(24시간 제한·출석 스탬프·문장 스크랩)를 이식한다.

**E.** 다음 액션 — 사업자등록증 준비 후 포트원 또는 토스페이먼츠에 **개인사업자 정기결제 신청 가능 여부와 심사 기간을 직접 문의.** 문서로는 확정할 수 없다. 부담되면 스티비 유료 뉴스레터(3.2%)로 과금 의사를 먼저 검증하는 2단계.

## 확인 못 한 것

- 한국 소비자의 앱 대 모바일 웹 결제 선호도·전환율 (검색 차단)
- 롱블랙 유료 구독자 수·매출
- 개인사업자의 정기결제 신청 가부를 명문화한 PG사 문서 — 배제 문구도 없고 확언도 없다
- 애플이 미국 아웃링크에 부과할 최종 확정 요율 (법원 결정 전)
