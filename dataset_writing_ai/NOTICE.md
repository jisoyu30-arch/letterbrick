# 데이터 라이선스 및 사용 의무

이 폴더(`dataset_writing_ai/`)에서 생성·수집·학습되는 데이터는 여러 라이선스 출처에서 옵니다. 각 출처별 의무를 반드시 준수해야 합니다.

---

## 1. AI Hub (한국지능정보사회진흥원, NIA)

`seeds/aihub_*/` 또는 `seeds/`에 AI Hub에서 다운로드한 데이터를 두는 경우 적용.

### 권리 귀속

AI Hub 데이터는 과학기술정보통신부와 한국지능정보사회진흥원(NIA)의 「지능정보산업 인프라 조성」 사업으로 구축됨. 데이터·AI 응용모델·저작도구 소스·매뉴얼 등 일체의 권리는 **수행기관 및 NIA**에 귀속.

### 2차 저작물 영리 활용 허용 (LetterBrick 핵심 근거)

> AI 데이터를 활용해 만들어진 2차 저작물(훈련으로 만들어진 지능형 제품·서비스, 챗봇 등)은 **영리적·비영리적 활용이 가능**합니다. (AI Hub 약관 본문)

- LetterBrick(학습된 모델로 운영하는 글쓰기 첨삭 서비스)은 **2차 저작물**로 분류되어 영리 활용 명시적 허용.
- 7항의 "상업적 이용 별도 협의"는 **데이터셋 자체의 판매·재배포** 케이스에 해당. LetterBrick은 데이터를 판매하지 않으므로 비적용.

### 핵심 의무 (전문은 AI Hub 데이터 페이지 참조)

1. **출처 표기 의무** — AI 데이터 이용 및 2차 저작물(학습 모델, 모델 기반 서비스)에 반드시 NIA 사업결과임을 표기.
2. **국외 소재 이용 금지** — 국외 법인·단체·개인이 이용하려면 수행기관 및 NIA와 별도 합의 필요.
3. **국외 반출 금지** — 데이터의 국외 반출 시 별도 합의 필요.
4. **학습용 한정** — 데이터 자체는 AI 학습모델의 학습용으로만 사용 가능. (단, 학습 결과물인 2차 저작물의 영리 활용은 별도 허용)
5. **재공유 금지** — 승인받지 않은 제3자에게 데이터 열람·제공·양도·대여·판매 금지.
6. **위반 책임** — 목적 외 이용, 무단 양도 등으로 발생하는 모든 민·형사 책임은 이용자(LetterBrick 운영자)에게 있음.
7. **데이터셋 자체의 상업적 이용은 별도 협의** — 데이터셋을 판매·재배포하려는 경우 수행기관과 별도 협의 필요. (LetterBrick은 비적용)
8. **개인정보 발견 시 신고** — 데이터셋 내 개인정보 발견 시 즉시 AI Hub에 신고하고 다운로드본 삭제.
9. **비식별 정보 재식별 금지** — 비식별 정보로 개인을 재식별하는 어떠한 행위도 금지.
10. **실태조사 협조** — NIA의 활용사례·성과 실태조사 시 성실 협조.

### LetterBrick 적용 사항

**(1항) 출처 표기 — 필수 액션**

LetterBrick 서비스 푸터·이용약관·개인정보처리방침에 다음 문구를 게재. 모델 카드·About 페이지에도 동일 또는 유사 문구 포함:

```
본 서비스의 일부 모델은 과학기술정보통신부와 한국지능정보사회진흥원(NIA)의
「지능정보산업 인프라 조성」 사업으로 구축된 AI 허브(aihub.or.kr) 데이터를 활용해
학습되었습니다.
```

영문 표기가 필요한 경우:
```
Some models in this service are trained using data from AI Hub (aihub.or.kr),
built under the "Intelligence Information Industry Infrastructure" project
of the Ministry of Science and ICT and the National Information Society Agency (NIA),
Republic of Korea.
```

**(2·3항 관련) 학습 인프라**
- 모델 학습은 **한국 리전 인프라**에서만 수행. 권장: AWS ap-northeast-2(서울), GCP asia-northeast3(서울), NHN/KT/네이버 클라우드 등.
- 학습 데이터를 미국·EU 리전으로 동기화 금지.
- Anthropic Claude API는 합성 페어 생성 시 시드 문장만 전송하므로 AI Hub 데이터를 직접 송신하지 않음(현재 파이프라인 기준). 향후 다른 LLM API에 AI Hub 원본 데이터 직접 전송 시 국외 반출에 해당할 수 있어 주의.

**(4·5항 관련) 모델 출력 처리**
- 학습된 모델의 출력에 AI Hub 원문이 그대로 재현되지 않도록 합성·변형 단계 필수. 본 파이프라인의 "거친 버전 → 다듬은 버전" 변형이 이 요건에 부합.
- 학습 산출물(모델 가중치, 데이터셋 가공본)을 NIA 승인 없이 외부에 배포·공유·판매 금지. 협력사·외주·오픈소스 공개 시 사전 검토.

**(8·9항 관련) 개인정보 처리**
- 다운로드 직후 데이터셋을 샘플링해 개인정보 포함 여부 점검.
- 의심 케이스 발견 시 AI Hub 신고 후 해당 데이터 삭제. 절대 학습에 사용 금지.

## 2. 위키문헌 (ko.wikisource.org)

`seeds/wikisource_seeds.jsonl` 적용.

- 라이선스: **CC BY-SA 4.0**
- 의무: 출처 표기(원작자·작품명) + 동일 라이선스 공유(파생 데이터를 외부 배포하는 경우).
- LetterBrick은 학습 데이터를 외부 공개하지 않으므로 SA(동일 조건 공유)는 학습 산출물(모델 가중치)이 데이터셋의 "각색물"로 해석될 가능성에 대한 예방 차원에서 출처 표기만 유지.
- 출처 표기 위치: LetterBrick 서비스 데이터 출처 페이지에 "위키문헌(ko.wikisource.org) 인용. CC BY-SA 4.0".

## 3. 모두의 말뭉치 (국립국어원, 신청 후 추가 시)

- 라이선스 조건은 신청 시 동의한 약관에 따름. 보통 비상업/상업 구분 있음.
- 신청서·약관 사본을 `legal/modu_corpus_agreement.pdf`로 보관.

## 4. Claude API 합성 페어 (`pairs/synthetic_pairs.jsonl`)

- 시드 문장(위키문헌·AI Hub 등)에서 파생된 합성 데이터.
- 시드 출처의 라이선스를 상속함. 즉 위키문헌 시드에서 만든 페어는 위키문헌 라이선스 의무, AI Hub 시드에서 만든 페어는 AI Hub 의무를 그대로 적용.
- 합성 데이터의 외부 배포·공유 시 시드 출처 라이선스 모두 충족해야 함. AI Hub 시드 기반 합성 데이터는 외부 배포 금지(5항).

## 운영 체크리스트

LetterBrick 출시 전 점검:

- [ ] 서비스 푸터·이용약관·개인정보처리방침에 NIA 출처 표기 게재 (필수)
- [ ] 모델 카드 또는 About 페이지에 학습 데이터 출처 명시
- [ ] 학습 환경이 한국 리전인지 확인 (AWS Seoul / GCP asia-northeast3 / 네이버·KT·NHN 클라우드 등)
- [ ] 학습 데이터 폴더가 git에 노출되지 않았는지 점검 (`git log --all -- dataset_writing_ai/seeds/` 빈 결과 확인)
- [ ] 학습 산출물(모델 가중치, 데이터 가공본)에 외부 접근 권한 분리
- [ ] 다운로드 데이터 샘플링해 개인정보 의심 케이스 점검 완료
- [ ] AI Hub 실태조사 대비 활용 기록(데이터셋별 사용 목적·일자) 작성
- [ ] 데이터셋을 외주·협력사에 공유할 일이 없도록 작업 분리. 부득이 공유 시 본 NOTICE 동의 후 분리된 폴더로 제공
